# Action: Make a pause between each actions

Modified on Fri, 16 Jun, 2023 at 9:57 AM

This action allows you to temporarily pause the process for a few seconds, **enabling you to wait for an external process**. Typically, users utilize this action to wait for an external script. Customers often add this action after executing an external program, although you have the flexibility to use it whenever needed.
